# Second Brain Synthesis

This module describes how to convert raw observations and existing vault content into high-quality updates for the Second Brain.

## Goal

Produce notes or updates that are:
- Accurate and well-attributed
- Genuinely useful for future retrieval and reasoning
- Naturally connected to existing knowledge
- Written in a voice that feels like an extension of Elnatan’s own thinking

## Synthesis Process

When you have observations + relevant vault context:

1. Review the material — What do you actually have, and what’s already in the brain?
2. Find the real insight — Don’t restate facts. Surface the meaningful pattern, decision, interest, or connection.
3. Ground it — Explicitly reference sources so nothing is invented.
4. Choose the right format:
   - New note (new topic or clear new insight)
   - Update to existing note (preferred when it adds real value)
   - Structured summary or list (for patterns or recurring decisions)
5. Add light, useful structure (headings, bullets, links) without over-engineering.
6. Attribute clearly.

## Quality Rules

- Never hallucinate connections.
- Prefer enriching existing notes over creating fragmented new ones (unless the topic is genuinely new).
- Keep things concise and scannable unless depth is clearly required.
- When uncertain, stay conservative and factual.

## Latency Awareness

Synthesis is expensive with large retrieval.

Best practices:
- Use targeted searches.
- Batch work instead of deep analysis on every minor observation.
- In live conversation, do lighter synthesis and defer heavier work.
- On a large vault, prioritize recent + high-signal content.
